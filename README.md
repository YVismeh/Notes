# یادداشت‌ها — Notes App

یک اپلیکیشن یادداشت‌برداری با رابط کاربری فارسی، راست‌به‌چپ، مینیمال و مدرن.
ساخته‌شده با Django و JavaScript خالص (بدون وابستگی سمت کلاینت).

A minimal, modern, Persian (RTL) notes app built with Django and vanilla JavaScript.

---

## ویژگی‌ها · Features

- ایجاد، ویرایش، حذف و سنجاق‌کردن یادداشت (بدون بارگذاری مجدد صفحه)
- جستجوی زنده با پشتیبانی از حروف عربی/فارسی (ي / ی و ك / ک)
- مرتب‌سازی: جدیدترین، قدیمی‌ترین، عنوان (الفبا)
- شش رنگ برای دسته‌بندی یادداشت‌ها
- حالت روشن / تاریک با ذخیره ترجیح کاربر
- اعلان (Toast) برای بازخورد عملیات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- فونت وزیرمتن به‌صورت محلی (بدون نیاز به اینترنت)

---

## اجرای پروژه · Run

```bash
# از داخل محیط مجازی پروژه:
python manage.py migrate
python manage.py createsuperuser   # اختیاری — برای پنل مدیریت
python manage.py runserver
```

سپس در مرورگر باز کنید: <http://127.0.0.1:8000/notes/>

پنل مدیریت: <http://127.0.0.1:8000/admin/>

## تست‌ها · Tests

```bash
python manage.py test notes
```

## ساختار · Structure

```
config/           تنظیمات پروژه و مسیرها
notes/            اپلیکیشن یادداشت‌ها (مدل، ویو، فرم، تست)
templates/        قالب‌های HTML
static/
  css/style.css   سیستم طراحی (تم، کامپوننت‌ها، انیمیشن‌ها)
  js/app.js       منطق سمت کلاینت (CRUD، جستجو، مرتب‌سازی، تم)
  fonts/          فونت وزیرمتن (woff2)
```

## میانبرها · Shortcuts

| کلید | عمل |
|---|---|
| `Esc` | بستن پنجره |
| `Ctrl/Cmd + Enter` | ذخیره یادداشت از داخل پنجره |
